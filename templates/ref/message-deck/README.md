# 메시지 중심 보고 템플릿 (4:3)

`templates/ref/gen_deck.js`의 메시지 전달 방식(흰 바탕 · 포인트 1색 · 초고굵기 한 줄 메시지 ·
라운드 카드 · 자간 넓은 아이브로우)을 가져오고, 거기서 약했던 **위치 정보**를 보강한 템플릿입니다.

## 위치 정보 장치

- **상단 장 레일** — 모든 본문 장표에 4개 장 칩. 현재 장만 채워짐
- **진행 바** — 레일 아래 3px 바가 덱 전체 진행률을 표시
- **페이지 카운터** — 우측 상단 `04 / 08`
- **목차** — 장별 한 줄 결론 + `p. 03 – 04` 페이지 범위 + 장 수
- **간지** — `CHAPTER 01 · p. 03 – 04` + "4개 장 중 1번째"

## 파일

| 파일 | 용도 |
| --- | --- |
| `message-deck-4x3-mint.pptx` | PPTX 템플릿 (민트 · 1종) |
| `message-deck-4x3-mint.pptx.layouts.json` | officedocs 사이드카 |
| `message-deck-4x3.html` | 장표 편집·미리보기용 (같은 폴더의 deck-stage.js 필요) |
| `deck-stage.js` | HTML 미리보기용 슬라이드 셸 |

## 장표 구성 (8장)

1 표지(프로토타입 title) · 2 목차 · 3 간지(프로토타입 section) · 4 본문 마커(프로토타입 content) ·
5 비교·전환 · 6 지표·차트 · 7 처방 3 · 8 도형 툴킷

## 마커

| 시맨틱 | 슬라이드 | 마커 → 필드 |
| --- | --- | --- |
| `title` | 0 | `프로젝트(솔루션)`→title, `문서(기능)`→subtitle, `YYYY. MM. DD`→date |
| `section` | 2 | `섹션 제목`→title |
| `content` 외 | 3 | `속지별 타이틀`→title, `프로젝트(솔루션)`→project · 본문 영역 `[0.067, 0.30, 0.867, 0.60]` |
