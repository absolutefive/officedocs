# 영업·경영진 보고 템플릿 (4:3)

차분하고 신뢰감 있는 톤의 보고용 템플릿입니다. 종이톤 바탕(#F7F5F0)과 포인트 색 하나,
헤어라인 괘선만으로 구성해 텍스트·표가 많은 실적 보고에 맞춘 고밀도 레이아웃입니다.

## 파일

| 파일 | 용도 |
| --- | --- |
| `exec-report-4x3-01-teal.pptx` | 컬러웨이 01 청록 (기본) |
| `exec-report-4x3-02-navy.pptx` | 컬러웨이 02 감청 |
| `exec-report-4x3-03-burgundy.pptx` | 컬러웨이 03 자적 |
| `exec-report-4x3-04-bronze.pptx` | 컬러웨이 04 브론즈 |
| `*.pptx.layouts.json` | officedocs 사이드카 (프로토타입 방식) |
| `exec-report-4x3.html` | 장표 편집·미리보기용 HTML (같은 폴더의 deck-stage.js 필요) |
| `deck-stage.js` | HTML 미리보기용 슬라이드 셸 |

슬라이드 크기는 4:3 (10 × 7.5 in, 1440 × 1080 px 기준 설계)입니다.

## officedocs로 빌드

```bash
officedocs build my-deck.md -t templates/exec-report/exec-report-4x3-01-teal.pptx -o report.pptx
officedocs layouts templates/exec-report/exec-report-4x3-01-teal.pptx
```

사이드카는 프로토타입 방식(예시 슬라이드 복제 + 마커 치환)으로 매핑됩니다.

| 시맨틱 | 프로토타입 슬라이드 | 마커 → 필드 |
| --- | --- | --- |
| `title` | 0 · 표지 | `프로젝트(솔루션)`→title, `문서(기능)`→subtitle, `작성자명`→author, `YYYY. MM. DD`→date |
| `section` | 1 · 간지 | `섹션 제목`→title, `프로젝트(솔루션)`→project / `01 / 04` 삭제 |
| `content` `two-content` `title-only` `blank` | 3 · 본문(마커) | `속지별 타이틀`→title, `프로젝트(솔루션)`→project / `섹션명` 삭제 |

본문 블록 영역은 `[0.058, 0.19, 0.884, 0.70]` (슬라이드 크기 대비 비율)입니다.
빌드 시 템플릿의 예시 슬라이드는 자동 제거됩니다.

## 템플릿에 들어있는 장표

| # | 장표 | 성격 |
| --- | --- | --- |
| 1 | 표지 | 프로토타입 (title) |
| 2 | 간지 | 프로토타입 (section) |
| 3 | 핵심 요약 | 지표 3 + 결론 3 + 부문표 + 판단 요청 |
| 4 | 본문(마커) | 프로토타입 (content) |
| 5 | 분기 추이 | 계획/실적 이중 막대 + 요약 지표 |
| 6 | 파이프라인 퍼널 | 단계별 금액·건수·전환율 |
| 7 | 로드맵 | 트랙별 간트 + 마일스톤 |
| 8 | 리스크·이슈 | 등급 칩 5열 표 |
| 9 | 마무리·승인 | 승인 요청 3건 + 다음 단계 |
| 10 | 도형 툴킷 | 장표 추가용 도형 세트 |

## 도형 툴킷 (10번 장표)

새 장표를 만들 때 10번 장표에서 도형을 복사해 쓰면 규칙이 유지됩니다.
상태 칩 / 번호 배지, 4단계 프로세스, 콜아웃 바(포인트·경고), 3분할 지표 카드,
진행률·퍼널 바, 타임라인 점 + 간트 바, 표 머리글·합계 행, 범례·각주·구분선.

## 디자인 규칙

- 바탕 `#F7F5F0` · 패널/표 머리글 `#EFEDE6` · 먹색 `#1E2328` · 헤어라인 `#D8D3C7` · 경고 `#A05A3C`
- 포인트 색은 컬러웨이별 1색 + 보조 1색 + 연한 톤 1색. 바탕·먹색·헤어라인은 4종 모두 동일
- 서체는 Pretendard 단일. 제목 자간 -0.03em, 라벨 자간 +0.14em
- 좌우 여백 84px 고정, 제목 44px / 본문 22–24px / 라벨·각주 19–20px (1440×1080 기준)
- 배경색은 2개까지만 사용 (종이톤 + 간지의 포인트 색)

## 재생성

디자인 원본은 `exec-report-template.dc.html`(예시 내용 버전)과
`marker-0*.dc.html`(마커 버전, 컬러웨이 4종)입니다. 마커 버전을 편집한 뒤 다시 pptx로
내보내면 템플릿이 갱신됩니다.
